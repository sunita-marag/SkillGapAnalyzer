# SkillGapAnalyzer

An AI-powered Skill Gap Analysis platform that helps candidates understand the difference between their existing skills and the skills required for their target job roles.

## About the Project

SkillGapAnalyzer is designed to evaluate candidate skills against job requirements and help identify areas where additional learning or improvement may be needed.

## Key Features

- Skill gap analysis
- Candidate skill evaluation
- Job requirement comparison
- Soft Skill Assessment
